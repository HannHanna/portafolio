# Portafolio Web - Xana Amalinalli Pérez Jiménez

## Portada
> **Autora:** Xana Amalinalli Pérez Jiménez  
> **Institución:** Instituto Tecnológico de Oaxaca  
* **Nombre del proyecto:** Portafolio Web Personal  
* **Descripción breve:** Portafolio web académico y responsivo para mostrar habilidades y proyectos de ingeniería.

## Descripción del Proyecto
* **Framework CSS:** Bootstrap 5 mediante CDN.
* **Plantilla específica:** Basada en componentes de Bootstrap para páginas de presentación.
* **Secciones:** Inicio, Sobre mí, Skills, Proyectos y Contacto.
* **Link de la plantilla:** [https://getbootstrap.com/docs/5.3/examples/]( https://bootstrapmade.com/iportfolio-bootstrap-portfolio-websites-template/)


## Proceso de Creación (Paso a Paso)
1. Selección y análisis de la plantilla: Se eligió un diseño limpio basado en Bootstrap 5 adecuado para un perfil de ingeniería.
2. Estructuración en index.html: Se adaptó el código HTML agregando las secciones principales de inicio, sobre mí, skills, proyectos y contacto.
3. Diseño personalizado en css/portafolio.css: Se creó el archivo de estilos para ajustar colores, detalles visuales y la foto de perfil formal.
4. Interactividad con js/portafolio.js: Se incorporó código de JavaScript vainilla para funciones básicas y navegación fluida.
5. Despliegue en GitHub Pages: Se subieron todos los archivos al repositorio público de GitHub y se activó GitHub Pages en línea.
